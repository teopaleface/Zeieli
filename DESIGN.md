# Zeieli storefront direction

Zeieli uses the familiar Romanian direct-response retail pattern:

1. orange promotional rail;
2. white header with navigation, search, account and cart;
3. three-item trust strip;
4. panoramic family lifestyle hero;
5. dense product grid;
6. functional footer.

## Tokens

- Background: `#FFFFFF`
- Text: `#292929`
- Muted text: `#686868`
- Surface: `#F5F5F5`
- Price: `#E2231A`
- Action: `#D93D0B`
- Action hover: `#B92F08`
- Font: Arial / Helvetica / system sans-serif
- Container: `1320px`
- Header group gap: `24px`
- Header search width: `272px`

## Product cards

Cards use square media, centered two-line titles, optional real review data,
red current pricing and an orange full-width purchase action. A compare-at
price is shown only when Shopify contains a real value larger than the current
price. Multi-variant products link to their product page instead of adding an
arbitrary variant.

## Responsive behavior

- Wide desktop (`>= 1361px`): four product columns and full search field.
- Compact desktop/tablet (`990–1360px`): navigation remains visible and search
  collapses to its icon so the header keeps clear spacing.
- Mobile: two product columns, icon search and a controlled portrait hero crop.
- Product grids never scroll horizontally.

## Claims and preview data

Trust-strip copy is editable in the Theme Editor and must reflect actual store
policies. Preview cards are clearly labeled and render only in Shopify design
mode. Public pages never fabricate products, ratings or discounts.
